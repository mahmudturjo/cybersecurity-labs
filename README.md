## 🧪 Completed Labs

### Pickle Rick – TryHackMe
**Focus:** Web Enumeration, Linux Privilege Escalation

**What I did:**
- Conducted network reconnaissance using **Nmap** to identify open services
- Enumerated a web application using **robots.txt** and HTML source inspection
- Identified command execution through a vulnerable web portal
- Bypassed restricted Linux commands to access sensitive files
- Escalated privileges via **sudo misconfiguration** to obtain root access

**Skills & Tools:**  
Linux, Nmap, Web Enumeration, Privilege Escalation, TryHackMe

**Key takeaway:**  
Minor misconfigurations can lead to full system compromise.
